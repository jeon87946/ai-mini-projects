# Experiment 001 — 실험 분석

## 1. 실험 목적
- 다양한 모델을 비교하여(4가지의 회귀 모델) 자전거 대여량을 여러가지 특성(온도, 계절, 시간, 체감온도 등)을 비교하여 예측하며 시각화 등의 방법으로 모델 성능을 비교한다.

## 2. 실험 조건
- 데이터: UCI Bike Sharing Dataset의 `hour.csv`
- 모델:DummyRegressor
      LinearRegression
      DecisionTreeRegressor
      RandomForestRegressor
- 평가 방법: Train(70%), Validation(15%), Test(15%)로 시간순 분할
            특성을 One-Hot Encoding과 Scaling으로 변환
            동일한 학습 및 데이터를 사용하여 모델별 성능 비교
            최종 모델로 Train과 Validation을 합쳐 재학습 후 Test 데이터로 평가

## 3. 실험 결과
- 평가 지표: MAE(실제값과 예측값의 평균적인 오차), RMSE, 결정계수
- 주요 결과: 여러 회귀 모델의 성능을 비교하여 모델별 예측 성능 차이를 확인하였다.
            최종 테스트에서 RandomForest(B) 모델이 MAE 82.31로 예측하여 Test 데이터에서도 예측 성능을 확인하였다.

## 4. 결과 해석
- 관찰한 결과: 출퇴근 시간대에 대여량이 증가하는 경향이 보였으며 특히 퇴근 시간에는 대여량의 변동이 커지며 예측 오차도 증가하였다
- 문제점 및 한계: 데이터를 시간순으로 분할하여 시기별 대여량 분포에 차이가 있었다. 이로 인하여 학습 데이터와 검증 및 테스트 데이터에도 분포 차이가 있어 성능에 영향이 미쳤을 가능성이 있다.
- 다음 실험 방향: 시간순 분할과 무작위 분할의 성능을 비교하여 데이터 분할 방식이 성능에 미치는 영향과 요인을 확인한다. 또한 연도별 또는 계절별로 데이터를 구분하여 대여량의 변화와 모델 성능 차이를 분석한다.
