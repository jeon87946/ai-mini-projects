## 2. 모델별 실험 결과 (CP-04~CP-06)

대표 설정별 Train MAE / Validation MAE를 기록합니다. 전체 실험 결과는 Notebook의 `results_df`에서 확인합니다.

- **DummyRegressor (mean):** Train 119.572 / Validation 194.109
- **LinearRegression:** Train 55.382 / Validation 99.725
- **DecisionTreeRegressor (`max_depth=12`):** Train MAE 32.966 / Validation MAE 79.959
- **RandomForestRegressor (설정 B):** Train MAE 22.255 / Validation MAE 64.517

**실험에서 발견한 점**

- **Decision Tree 깊이 변화에 따른 성능:** 깊이가 깊어질수록 예측 성능이 좋아지고 있다.
- **Random Forest 두 설정의 차이:** 하이퍼파라미터 설정값이(의사결정나무, 최대 깊이) 다르다
- **Train·Validation 성능 차이에서 관찰한 현상:** 훈련데이터에서는 성능이 상대적으로 잘 맞추지만 검증 데이터에서는 예측 성능이 차이가 났다. cnt 평균 차이로 인해 학습 데이터와 검증 데이터의 예측이 달라졌을 가능성이 있다.(`001_data_analysis`의 2절 `cnt` 평균 차이와 연결해 작성)

## 3. 예측 오류 분석 (CP-07)

- **시간대별 MAE가 큰 구간:** 17시
- **모델이 상대적으로 잘 예측하지 못하는 상황:** 17시~18시 퇴근 시간에 예측 성능이 낮다.
- **(선택) 특성 중요도에서 확인한 점:** hour, temp 등과 같이 시간대와 기온 등과 같은 환경적 요인이 중요도로 나타난다.

**분석:** 이 오류가 최종 모델 선택에 어떤 영향을 주었는지 작성합니다.  
다른 모델에서는 상대적으로 MAE값이 더 크거나, 비슷한 값이 나왔다. RandomForest(B)의 경우에는 MAE의 값이 상대적으로 편차가 크고 17시~18시에 값의 오차가 작아 성능에서 강점을 보였다. 이러한 예측 성능을 고려하여 RandomForest(B)를 선택하였다.

## 5. 실험 요약

- **가장 중요한 실험 결과:** 랜덤포레스트 모델이 다른 모델에 비해서 상대적으로 우수한 예측 성능을 보여 여러 특성을 활용한 모델인 랜덤포레스트가 예측 성능에 강점을 보인다고 알게 되었다.
- **남아 있는 모델의 한계:** 시간순으로 데이터 분할을 하여 계절과 온도 등과 같은 차이점이 발생할 가능성이 있으며 휴일과 온도, 시간 등에 따라서 예측 오차가 커지는 걸 알 수 있었다.
따라서 다양한 요인이 복합적으로 있을 경우 완벽한 반영은 어렵다는 것이 한계이다.
