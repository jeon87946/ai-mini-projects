## NLP — BERT 기반 한국어 의미 검색 시스템 개발 및 성능 비교

### 의사결정 ① 활용 목적과 우선 평가 지표 선택 (CP-07~CP-09)

**문제**

검색 시스템의 활용 목적에 따라 첫 번째 검색 결과의 정확성, 상위 후보에 정답이 포함되는지, 정답 문서의 순위 중 무엇을 더 중요하게 평가할지 결정해야 합니다.

- **가정한 활용 상황(`USE_CASE`):** 
사용자가 질문을 입력하여 관련 문서에서 답변에 필요한 정보를 찾는 문서 검색 서비스
- **검토한 지표:** Hit@1, Recall@3, MRR@5
- **최종 우선 평가 지표(`PRIORITY_METRIC`):** Hit@1
- **선택 근거(사용자가 검색 결과를 어떻게 활용하는지):** 
사용자가 질문을 입력했을 때 가장 먼저 제시되는 문서가 실제 정답 문서인지 확인하는 것이 중요하므로 Hit@1을 우선 평가 지표로 선택하였다. 검색 결과의 첫 번째 문서가 정답이라면 사용자가 추가로 다른 문서를 확인하지 않아도 되기 때문이다.
- **함께 고려할 다른 지표 또는 제약:** 
첫 번째 검색 결과에서 정답을 찾지 못하는 경우를 고려하여 Recall@3과 MRR@5도 함께 확인한다. Recall@3은 상위 3개 문서 안에 정답이 포함되는지 평가하고, MRR@5는 상위 5개 문서에서 정답이 얼마나 높은 순위에 위치하는지 평가한다.

**분석 근거:** `02_nlp_model_analysis.md`의 2~4절

### 의사결정 ② 최종 검색 방식 선택 (CP-09)

**문제**

문자 기반 TF-IDF, 일반 BERT의 Mean Pooling, Sentence-BERT 검색 방식의 성능과 특성을 비교하여 최종 검색기를 선택해야 합니다.

- **비교한 선택지:** TF-IDF / BERT / Sentence-BERT
- **최종 선택한 검색 방식(`SELECTED_METHOD`):** 'tfidf' (`tfidf`, `bert`, `sbert` 중 하나)
- **선택 근거(`SELECTION_REASON`, 실제 Validation 수치와 검색 실패 사례를 활용):** 최종 선택한 TF-IDF 모델은 Validation에서 Hit@1 0.883, Recall@3 0.967, MRR@5 0.917로 세 지표 모두 가장 높은 성능을 보였다. Test에서는 각각 0.800, 0.800, 0.813으로 Validation보다 낮아졌다. 특히 Test 질문 20개 중 16개는 정답 문서를 1위로 검색했으며, 나머지 4개는 1위 검색에 실패하였다. 따라서 전체적인 검색 성능과 최우선 평가 지표인 Hit@1을 고려하여 TF-IDF를 최종 선택하였다.
- **트레이드오프(다른 방식과 비교해 얻은 장점과 감수한 단점):** TF-IDF는 단어가 정확하게 일치하는 질문에서 높은 검색 성능을 보였으며, BERT와 Sentence-BERT보다 이번 Validation 데이터에서 세 가지 평가 지표 모두 우수했다. 반면 질문과 문서의 표현이 다르거나 문맥을 통해 의미를 파악해야 하는 경우에는 정답 문서를 놓칠 가능성이 있다. BERT와 Sentence-BERT의 문맥 및 의미 기반 검색 성능을 충분히 활용하지 못한다는 점도 감수해야 할 단점이다.
- **추후 확인할 점(실제 사용 데이터, 검색 처리 비용 등):** 실제 사용 데이터에서는 질문의 평균 글자 수가 약 29자이고 문서의 평균 글자 수는 약 500자로 차이가 있었다. 따라서 짧은 질문으로 긴 문서에서 관련 정보를 정확하게 찾을 수 있는지 추가로 확인할 필요가 있다. 또한 실제 데이터의 양이 증가했을 때 검색 속도와 메모리 사용량이 어떻게 달라지는지 확인할 필요가 있다.

**분석 근거:** `02_nlp_data_analysis.md`, `02_nlp_model_analysis.md`의 3~4절, `outputs/reports/cp09_selection.json`
